Panduan Upload Animasi ke Modul DMZ Dual Eye

1

Buat Animasi GIF

Gunakan tab "Video → Animasi Mata" atau "Resize GIF" di atas untuk membuat file GIF 240×240 px. Pastikan ukurannya tidak melebihi sisa ruang flash di modul.

2

Hubungkan ke WiFi Modul

Nyalakan modul DMZ Dual Eye. Di smartphone atau laptop Anda, sambungkan ke WiFi:

SSID: DMZ-Eye-Setup
Password: dmzeye123
3

Buka Halaman Konfigurasi Modul

Buka browser dan kunjungi http://192.168.4.1. Anda akan melihat halaman konfigurasi modul berisi editor mata kiri & kanan, halaman upload, dan pengaturan WiFi.

4

Upload File GIF

Di halaman web modul, gunakan fitur upload untuk mengunggah file GIF yang sudah dibuat. Perhatikan "Maks upload baru" untuk mengetahui sisa ruang flash. Upload hanya diterima jika file berupa GIF89a, resolusi tepat 240×240, dan ukurannya cukup.

5

Pilih Animasi di Editor Mata

Setelah upload berhasil, buka editor mata kiri atau kanan. Pilih GIF baru dari daftar, atur rotasi / zoom / geser sesuai selera, lalu simpan. Animasi baru akan langsung tampil di TFT!
